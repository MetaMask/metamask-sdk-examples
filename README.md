## ✨ Why move to MetaMask Connect?

- **One integration → all MetaMask-supported chains**
- **Built on the Multichain API** (auto-support for new chains)

- **Simpler APIs** with fewer edge cases
- **Better connection reliability**
- **Works with modern connector stacks** (Wagmi, more coming soon)
